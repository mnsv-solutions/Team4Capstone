# Credit Pulse - Frontend

A Digital Loan Origination & Credit Assessment Platform.

This project is built using [Next.js](https://nextjs.org/) bootstrapped with `create-next-app`.

## Getting Started

First, make sure to install dependencies from the root directory:

```bash
npm install
```

Start the development server from the root of the project:

```bash
npm run start:local:frontend
# or run the entire application
npm run start:local
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Technologies Used
- [Next.js](https://nextjs.org/) (React Framework)
- Tailwind CSS
- React Router

## Scripts
You can run the following npm scripts specifically for the frontend from the root of the project:
- `npm run build:frontend` - Builds the Next.js application for production.
- `npm run test:frontend` - Runs tests for the frontend.
- `npm run start:local:frontend` - Starts the frontend in local development mode.
- `npm run start:dev:frontend` - Starts the frontend in development mode.
- `npm run start:prod:frontend` - Starts the frontend in production mode.
